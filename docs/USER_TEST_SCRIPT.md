# 5-30 朋友测试 · 30 分钟引导脚本

> 给主持人（你）在朋友面前用的逐字脚本。**短句、可一眼扫**。慌的时候照念。
>
> 配套：[`USER_TEST_PROTOCOL.md`](USER_TEST_PROTOCOL.md) 是大背景, 本文件是当天执行。

---

## 准备（朋友到之前 10 分钟）

- [ ] Trae SOLO 桌面端已打开, `.agents` 技能目录开关 ON
- [ ] 输入框试打"砚友"看是否自动识别 yanyu-dialogue skill
- [ ] 准备 3-5 个**朋友熟悉**的研磨候选主题（**不是你熟悉的**）
- [ ] 录音/录屏：**问过朋友是否允许**, 不允许就不录, 用纸笔
- [ ] [`USER_TEST_RESPONSES.md`](USER_TEST_RESPONSES.md) 或飞书表单链接打开
- [ ] 把所有跟砚友相关的页面/文档**关掉**（朋友扫一眼到 SKILL.md 你这次测试就废了）

---

## 阶段 1 · 介绍（0-3 min）

### 你说

> "我最近在试一个学习工具。它跟 ChatGPT 不一样——你问它问题它不直接给答案, 它**反问你**, 逼你自己想出来。我请你试 30 分钟, 然后告诉我感受。"

**就这 3 句**。

### 朋友可能问

| 朋友说 | 你说 |
|---|---|
| "这是你做的吗？" | "我在帮一个项目测——你的反馈很重要"（不暴露你是作者, 避免客套）|
| "我不太懂 AI" | "正好——它是给普通人用的, 你卡住的地方就是 bug"（**不要解释技术**）|
| "我该问什么？" | "下一步会有具体题目, 你先放轻松"（**不要泄题**）|
| "需要登录什么吗？" | "都是本地的, 你只要打字就行" |

### 不能说

- ❌ "这是个苏格拉底式学习工具"——技术词
- ❌ "它基于飞书知识库 / RAG / Skills 协议"——朋友 30 秒注意力没了
- ❌ "它会让你被问住"——把朋友 prime 了 negatively
- ❌ "它特别厉害 / 特别新"——cheerleading prime

---

## 阶段 2 · Grinding 研磨（3-15 min, 约 12 分钟）

### 你说

> "第一件事：你最近学过 / 看过的一个**专业话题**, 选一个你自己也没完全搞透的。"

**等朋友抛出来一个**（"我最近在看 RAG / 我学了点 React Hooks / 我在搞肌肉训练分化"）。

### 你说

> "好。你现在打开砚友, 输入：『我想深挖 <ta 说的话题>』, 让它问你。"

### 朋友打字的同时, 你做什么

| 你做 | 你不做 |
|---|---|
| 安静看屏幕 | **不要替朋友打字** |
| 朋友卡住超 30 秒 → 说"你慢慢想, 没事" | **不要解释 agent 为啥这么问** |
| 朋友答错 / 跑题 → 沉默, 等 agent 接 | **不要替 agent 圆场**（"它的意思是…"）|
| 笔录情绪节点（笑 / 皱眉 / 烦）| **不要打断节奏问"你现在感觉怎样"** |

### 朋友会有的典型反应（脚本里**不接**, 让 agent 自己接）

- 朋友："不知道。" → **闭嘴, 看 agent 怎么回**
- 朋友："这玩意儿没完没了。" → 笔录 + 闭嘴
- 朋友："直接告诉我吧。" → **特别关键, 看 agent 是不是真的"不投降"**——这是决策 7 hint laddering 的核心测点
- 朋友：去飞书翻原文 → **关键决策 7 测点**, 看 agent 是不是触发了 L3 让朋友去查 + 朋友是不是用自己的话复述

### 你必须忍住不做的

- ❌ 朋友卡 2 分钟你忍不住给提示——这次测试当场作废
- ❌ 朋友说"我觉得 agent 烦"你辩护"它就是要烦你你才会想"——你在替 agent 找借口
- ❌ 朋友想跳到下一个 → "再坚持 1 个问题就行"——别强求, **接受朋友想跑**, 直接进 fusion

### 12 分钟到了 / 朋友想停 / 朋友 ahabra 了

> "好, 我们换一下。第二件事。"

### Grinding 段结束你笔录

- session 大概几轮?
- 朋友被问住过吗? 几次?
- 朋友主动放弃过吗? 怎么放弃的?
- agent 触发了 L1/L2/L3 哪几档?（用 session.json 后面对照）
- 砚石痕迹 callout `🪨` `📿` 出现时朋友有反应吗?

---

## 阶段 3 · Fusion 研创（15-27 min, 约 12 分钟）

### 你说

> "现在反过来——你**最近有什么想做但说不清楚的**事？工作的、生活的、副业的都行。"

**等朋友抛**。常见："我想做个公众号但没想清主题 / 我想转岗但不知道转哪 / 我想搞个 side project / 我想做个研究但定不下题"。

### 你说

> "把这个想法输给砚友, 让它跟你碰一碰。"

### 朋友打字的同时, 你做什么

- 看 agent 是不是真的跨界（抛了一个看起来不相关的 A 领域）
- 看朋友被跨界问题问到时**第一反应**是什么——困惑? 笑? 觉得荒谬? 还是真的开始想?
- 笔录朋友说"哦……" / "我想想" / "这玩意儿什么意思啊" 等所有自发出声

### 关键测点（fusion 独有）

- 朋友被问"如果让 <A 领域> 解决 <B 领域>" 时, ta 是逃避（"这俩没关系"）还是真去想?
- agent 是不是真的把朋友**自己说过的金句**甩回脸上？（决策 2 砍掉的 Step 5 喂答案后, agent 唯一能用的就是甩用户原话）
- 朋友收敛了吗? 收敛信号 = 朋友开始用具体动词（"先做 X, 再做 Y"）
- 假收敛（"懂了懂了" 但讲不出方案）—— agent 应该继续质疑而不是收尾

### 12 分钟到了 / 朋友收敛了 / 朋友说"够了"

> "好, 最后 3 分钟我问你几个问题。"

---

## 阶段 4 · 5 题问卷（27-30 min）

### 你说

> "5 个问题, 1 分钟一个, 想到啥说啥, 不要客气。"

### 5 题 + 主持人追问模板

**Q1: 你被问住过吗? 被问住时是什么感觉?**

- 朋友说"被问住了" → 追问"哪一次? 当时第一反应是什么?"
- 朋友说"没被问住" → 追问"是太简单还是 agent 没问到点上?"
- 朋友说"还行" → 追问"还行是说被问住了不爽, 还是被问住了爽?"

**Q2: agent 拒绝直接给答案, 你想砸键盘吗?**

- 朋友说"没有" → 追问"一次都没有? 哪些场景接近临界?"
- 朋友说"想过" → 追问"具体哪一轮? 当时它说了什么?"

**Q3: 最后你有"我悟到了"的瞬间吗? 发生在哪一轮?**

- 这是 aha-moment 关键测点
- 朋友说"有" → 追问"具体那一轮 agent 问了什么? 你之前怎么想的?"
- 朋友说"没有" → **不要失望**, 这是真实信号, 笔录就好

**Q4: agent 的提问, 有没有让你想到自己之前没想过的角度?**

- 这测的是研磨深度（不是 telling）
- 朋友说"有" → 追问"具体哪个角度? 是 grinding 还是 fusion 段?"
- 朋友说"没有" → 追问"那对话过程对你来说像什么? 像考试 / 像聊天 / 像被烦?"

**Q5: 如果朋友跟你描述这个产品, 你会推荐给谁?**

- 这测的是产品定位是不是清晰
- 朋友说"会推荐给 X" → 追问"为什么是 X 不是 Y?"
- 朋友说"不会推荐 / 不知道推给谁" → **关键负信号**, 追问"那它的核心问题是什么?"

### 笔录铁律（再说一遍）

- 用朋友**原话**, 不润色
- 情绪信号专门记（"这里笑了 / 这里翻白眼 / 这里皱眉"）
- 朋友说"还行 / 一般 / 都行 / 大概" → **追问**

---

## 阶段 5 · 收尾（30 分钟硬刹车）

### 你说

> "好, 谢谢你 30 分钟。我下周再找你聊。"

### 不能做

- ❌ 朋友想多聊砚友设计 / 想看代码 → 婉拒"下次, 今天先到这"
- ❌ 朋友说"这玩意儿不行" 你想辩护 → 笔录, 闭嘴
- ❌ 朋友走前问"你的项目是这个吗" → 承认, 但**不要推销**

---

## 朋友走后 5 分钟内必须做的

1. **抓 session.json**（如果有自动落地）跑 `python3 -m eval.judge --session <path> --mock`
2. 看 `_ladder_stats`：L1/L2/L3 实际触发几次? 跟朋友主观体感对得上吗?
3. 看 `telling_rate`：是否真的 ≤ 0.2? 如果朋友抱怨"它告诉我太多了" 但 telling_rate ≤ 0.2 = prompt 有 false-negative 漏标
4. 在 [`USER_TEST_RESPONSES.md`](USER_TEST_RESPONSES.md) 落地这次测试的: 朋友昵称 / mode / 5 题答 / 你的观察笔录 / session_path / metrics 摘要

**当天**：3 个朋友测完 → 当天晚上你**不要做分析**, 让数据沉淀一晚。第二天 6-1 早上再回头看。

---

## 心理准备（给主持人）

- 朋友给的反馈大概率会**让你不爽**——这是真信号的特征
- 朋友说"还行 / 没特别感觉" 比 "太棒了" 更有用——后者大概率社交礼貌
- 至少 1 个朋友可能会说"我不会再用"——**记下来, 不辩护, 不解释**
- 你的目标不是"证明砚友好"——是"找出砚友哪里坏"

这是决策 4 真正的意义：破"作者自评双重幻觉"。
